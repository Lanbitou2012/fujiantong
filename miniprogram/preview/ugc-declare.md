# UGC 内容声明（黄金版本 v1.0）

> 提审用文案模板，对应 `wxa/submit_audit` 接口的 `ugc_declare` 字段。

---

## 完整声明

本小程序为附件分享工具，**内容由作者用户自主上传与发布**。平台严格遵循微信小程序 UGC 内容管理规范：

### 1. 内容审核机制

- **机审**：所有图片、音频类附件上传时自动调用微信内容安全 API（`mediaCheckAsync`）进行机器审核
- **复审**：文档类附件（PDF / Word / Excel / PPT 等）由平台专人进行人工复审，72 小时内完成
- **抽检**：已发布内容定期抽检违规内容并下架处理

### 2. 用户举报通道

- 小程序内每个附件详情页底部均提供「客服微信」联系入口
- 用户可通过客服微信举报违规内容
- 平台承诺 **24 小时内** 响应所有举报

### 3. 违规处置

发现违规内容时，平台将立即：
1. 下架违规附件
2. 限制涉事作者上传权限（视情节）
3. 协助配合平台与监管部门调查

### 4. 资质对应

- **个人主体作者**：上传仅限于本人创作或已获授权使用的内容
- 作者上传时需勾选合规承诺书，对内容真实性、合法性、原创性承担全部责任

### 5. 平台主体责任

- 附件通作为技术服务提供方，依规履行 UGC 平台审核义务
- 不直接生产、编辑内容
- 严格遵循《互联网信息服务管理办法》《网络信息内容生态治理规定》等相关法律法规

## ugc_declare 字段映射

```json
{
  "scene": [1, 2, 3, 4, 5],
  "method": [1, 2, 3, 4, 5],
  "has_audit_team": 1,
  "audit_desc": "本小程序内容由作者用户自主上传，平台对图片/音频走机审，文档类走人工复审，发现违规内容立即下架。客服微信 fjt_helper 7×24 接受举报。"
}
```

字段说明（按微信文档）：
- `scene`: [1=社交, 2=媒体, 3=娱乐, 4=电商, 5=资讯]
- `method`: [1=平台审核, 2=用户举报, 3=AI 审核, 4=人工审核, 5=违规处罚]
- `has_audit_team`: 1=有专人审核团队
